# Threadwyn for Android

On an Android phone, tap **[Download Threadwyn](https://github.com/Abookofhope/threadwyn-updates/raw/main/threadwyn.apk)**,
then open the file to install. A newer file installs over an older one and keeps everything on the phone.

The app checks [version.json](version.json) here to tell you when a newer version is ready.
